A deadpan one-star review of gravity, the everyday essential that does nothing all day and only shows up the moment your phone is falling. `main.ts` writes the single-line review (at most 160 characters) to `entry.txt`.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/review-out node main.ts
```
